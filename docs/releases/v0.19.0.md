# Corelia v0.19.0: Studio, blog viết trong Admin, trang học và landing mới

Tổng hợp thay đổi giữa `v0.18.2` và `main`: #754, #835–#867, #869, #870 và PR duyệt migration cho Production. Có 41 migration database.

## Studio (#754, #839, #842–#845, #848–#851, #854, #855, #862)

- Studio tạo khóa học bằng AI: brief, curriculum, bài học, video, dịch đa ngôn ngữ, vòng review bài học và kiểm tra link.
- Chạy lại từ curriculum, giữ bản dịch khi resume, fallback chẩn đoán khi một bước lỗi, ghi nhận sự cố vận hành.
- Bucket `studio-assets` và ngữ cảnh khóa học cho Studio.

## Ảnh bìa khóa học AI (#840, #846, #847, #853)

- Ảnh bìa vẽ tay cho khóa học AI, có fallback thumbnail và hiển thị ở các mục trang chủ.

## Blog viết trong Admin (#870)

- Bài blog và case study chuyển từ file Markdown trong repo sang bảng `public.blog_posts`. Admin/support viết, lưu nháp, đăng và gỡ bài ở Admin → Blog, không cần deploy.
- Landing đọc bài đã đăng trực tiếp từ database (cache 60 giây); bản nháp không công khai. Thêm `/sitemap-blog.xml`.
- 66 bài đã đăng và 8 bản nháp hiện có được seed sẵn, giữ nguyên URL.
- Ảnh bài viết tải lên `cdn/blog/`.

## Trang học (#835–#838, #841, #856–#861, #864–#867)

## Landing và khác (#863, #869)

## Lưu ý khi deploy

- Trang chủ landing được prerender và đọc `blog_posts` lúc build. Cloudflare build `corelia-landing` ngay khi merge vào `main`, trước khi migration Production chạy, nên bản build đó sẽ lỗi `blog_posts_404`; trang đang chạy không bị ảnh hưởng. Sau khi `Deploy Production` xong, bấm Retry build cho `corelia-landing`.
- Trước khi migration chạy, `corelia-app` bản mới đã có Admin → Blog nhưng chưa dùng được.
